#🎓 Student Data Organizer

## 📌 Project Overview

The **Student Data Organizer** is a menu-driven Python application designed to manage student information efficiently. It allows users to add, display, update, and delete student records through a simple interactive menu.

The project uses Python lists, dictionaries, loops, conditional statements, and user input to organize student data.

## 🌐 Live Project

🔗**Hosting URL:**🔗 [Run Student Data Organizer on OnlineGDB](https://onlinegdb.com/LelN7f9wy)

## ✨ Features

1. **Add Student:** Add a new student by entering their ID, name, age, grade, date of birth, and subjects.
2. **Display All Students:** View the information of all students stored in the program.
3. **Update Student Information:** Update a student's age and subjects using their student ID.
4. **Delete Student:** Remove a student record by entering the student's ID.
5. **Display Subjects Offered:** Display the list of subjects available for students.
6. **Exit:** Exit the program safely.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Platform:** OnlineGDB
- **Concepts Used:** Lists, dictionaries, variables, user input, `if-elif-else` conditions, `for` loops, `while` loops, and list methods.

## ⚙️ How to Run the Project

1. Open the [Student Data Organizer on OnlineGDB](https://onlinegdb.com/LelN7f9wy).
2. Run the Python program.
3. Select an option from the displayed menu by entering a number from 1 to 6.
4. Follow the instructions and enter the required student information.
5. Continue using the menu until you select option 6 to exit.

## 📚 Python Concepts Demonstrated

- **Lists:** Store multiple student records.
- **Dictionaries:** Store each student's information as key-value pairs.
- **Input and Output:** Accept information from the user and display results.
- **Conditional Statements:** Execute different operations according to the selected menu option.
- **Loops:** Keep the menu running until the user chooses to exit.
- **List Methods:** Use `append()` to add student records and `remove()` to delete records.
- **Boolean Variables:** Use a `found` variable to check whether a student ID exists.

## 🎯 Project Objective

The main objective of this project is to develop basic Python programming skills by creating an interactive system for managing student information. It demonstrates how different Python concepts can be combined to perform common data management operations.

## 🏁 Conclusion

The Student Data Organizer is a beginner-friendly Python project that provides a simple way to manage student records. It helps develop practical knowledge of data structures, loops, conditional statements, and user interaction. This project also builds a foundation for developing more advanced student management systems in the future.
